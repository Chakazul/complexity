# Papers

The papers behind the complexity measures, one or more per measure, as cited in
[MEASURES.md](../MEASURES.md) §2.4. The PDFs are kept locally in this folder but are not in
the repository (`.gitignore`); the filename column says what to name a downloaded copy so
the notes find it. [Complexity_Measure.pdf](Complexity_Measure.pdf), the overview of the
measures ("the PDF" in MEASURES.md), is in the repository.

Citations are APA 7. Where the local PDF is a preprint or working paper, the citation is to
that version and the published version follows.
